🤖 Configuração do Bot Telegram
1. Fale com @BotFather no Telegram
2. Envie /newbot e siga as instruções
3. Copie o Token e adicione como Secret no GitHub:
TELEGRAM_TOKEN
4. Cada usuário entra no bot e manda /start
5. Use @userinfobot para descobrir o Chat ID de cada usuário
6. Cadastre o Chat ID no perfil do usuário em ⚙️ Admin → Usuários
⚙️ Secrets necessários no GitHub Actions:
Repositório → Settings → Secrets → Actions
TELEGRAM_TOKEN · ALERT_DAYS · CHECKLIST_DAYS
